Engineer reference: use these components for React implementation

⚙️ Component API Reference for Engineers

Copy-paste the exact prop names and types. Do NOT invent props that aren't listed here.

Button Component

<Button   variant="primary" | "secondary" | "ghost" | "danger" (optional, default: "primary")   size="sm" | "md" | "lg" (optional, default: "md")   loading={boolean} (optional, default: false)   disabled={boolean} (optional)   className={string} (optional)   onClick={handler} (optional) >   Button text </Button>

❌ WRONG: fullWidth, width, p (padding) are NOT props. Use className="w-full" instead.

Card Component

<Card   variant="default" | "elevated" | "interactive" (optional, default: "default")   padding="none" | "sm" | "md" | "lg" (optional, default: "md")   className={string} (optional) >   Card content here </Card>

❌ WRONG: padding="xl" or p="lg". Only none, sm, md, lg are valid. For larger padding, use className="p-12".

FormField Component

<FormField   label="Field Label" (required)   id="field-id" (optional, auto-generated if omitted)   type="text" | "email" | "password" | ... (optional, default: "text")   placeholder="..." (optional)   required={boolean} (optional)   error="Error message" (optional)   helpText="Help text" (optional)   fullWidth={boolean} (optional, default: true) />

❌ WRONG: htmlFor (use id instead); help (use helpText); label as a prop inside children (use the label prop).

Input Component

<Input   id="input-id" (optional)   type="text" | "email" | "password" | ... (optional, default: "text")   placeholder="..." (optional)   value={string} (optional, for controlled inputs)   onChange={handler} (optional)   error={boolean} (optional, adds error styling)   fullWidth={boolean} (optional, default: true)   disabled={boolean} (optional) />

Use FormField for labeled inputs (recommended); use Input directly only for inline/simple cases.

Remember: All components support className for Tailwind CSS overrides. Don't invent new props—use Tailwind classes for styling.

Product Card (Storefront)

Used in product grids on public storefronts. Shows product image, title, price, rating, and stock status.

Structure

<ProductCard>   <image src="..." alt="..." />   <title>Product Name</title>   <price>$XX.XX</price>   <rating>★★★★☆ (24 reviews)</rating> (optional)   <badge>In Stock</badge> (optional) </ProductCard>

Visual Reference

In Stock

Behavior: Hover lifts card up 2px with box-shadow. Click navigates to product detail page.

Mobile: Remove shadow, keep lift effect subtle. Text may wrap to 2 lines.
