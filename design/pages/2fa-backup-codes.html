How to Use Backup Codes
  1. Store safely: Save these codes in a password manager, a secure note app, or print them out and store in a safe place.
  2. Use when needed: If you lose your authenticator app, you can enter a backup code instead of a 2FA code to sign in.
  3. One-time use: Each code can only be used once. Once used, it will no longer work.
  4. Regenerate: If you use all your codes, you can generate new ones in your account settings.
