Feature F11 & F12: Order Dashboard with Status Updates

✓ F11: Seller order dashboard — Seller logs in, sees table of all orders (Order ID, Customer, Total, Status).
✓ F12: Order status updates (dropdown) — Seller marks order as: pending → paid → in-progress → shipped → delivered. Customer notified on status change.

Below is the canonical design for inline status editing. The engineer should implement the Status column as a <select> dropdown (not a badge display) so sellers can change status without leaving the dashboard.

Design Notes for Engineer

  • Status Column: Use native HTML <select> element (not a styled button + popup). This ensures accessibility and native mobile behavior.
  • Focus State: When focused, select has a 3px slate-blue box-shadow and solid border (shown in design/system/components.html).
  • Options: Always show 5 options in order (Pending, Paid, In Progress, Shipped, Delivered). Pre-select the current status.
  • On Change: When user selects a new status, POST to /api/orders/{orderId}/status with new status. Show loading state (slight opacity or spinner icon). On success, update the dropdown value. On error, revert and show toast error.
  • Customer Notification: When status changes, automatically send email to customer (this is F12 requirement). Email template is in design/emails/order-confirmation.html.
  • Mobile: Select remains full-width on mobile (< 768px). Native dropdown opens with all options visible.

Related Features (Acceptance Criteria)

  • F11 ✓: Seller can view a list of all orders (Order ID, Customer email, Total, Status) without filtering or date range.
  • F12 ✓: Seller can change status from any state to any state using dropdown. Valid transitions: pending → paid → in-progress → shipped → delivered (but non-sequential transitions allowed for demo).
  • F13 (Tracking): Separate column (not shown here) for "Tracking ID" input. See design/pages/order-detail.html for full order view with tracking input.
  • F16 (Customer Email): When status changes, customer receives email with new status. Subject: "Your order #ORD-XXX status updated" Body: "Your order is now [STATUS]."
