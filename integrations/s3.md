# S3 Integration — Product Image Upload

**Provider:** AWS S3 or DigitalOcean Spaces
**Purpose:** Store and serve product images uploaded by sellers
**Features Used:** F4 (Product image upload to S3)
**Sandbox:** Yes — use DigitalOcean Spaces test credentials

---

## Overview

Solo Shop Builder uses AWS S3 (or compatible services like DigitalOcean Spaces) to store product images uploaded by sellers. Images are uploaded via a secure API endpoint, stored in a public bucket, and served via CDN URLs for fast delivery to customers browsing shop storefronts.

**Key capabilities:**
- Upload product images (JPEG, PNG, WebP, GIF) up to 5MB
- Automatic filename sanitization and timestamping to prevent collisions
- Public-read ACL for direct customer access
- CDN URL generation (CloudFront for AWS, Spaces CDN for DigitalOcean)
- Fallback to local filesystem storage if S3 is not configured

---

## Provider Options

### AWS S3 (Production)
- Set `S3_PROVIDER=""` or `S3_PROVIDER="aws"` in `.env`
- Requires: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_S3_BUCKET`, `AWS_REGION`
- Optional: `AWS_CLOUDFRONT_URL` for CDN acceleration

### DigitalOcean Spaces (Alternative)
- Set `S3_PROVIDER="digitalocean"` in `.env`
- Requires: `AWS_ACCESS_KEY_ID` (Spaces access key), `AWS_SECRET_ACCESS_KEY` (Spaces secret), `AWS_S3_BUCKET`, `DO_SPACES_REGION`, `DO_SPACES_ENDPOINT`
- Automatically constructs CDN URL: `https://{bucket}.{region}.cdn.digitaloceanspaces.com`

## Configuration

### Environment Variables

Add these to `.env` (already present in `.env.example`):

```bash
# S3 Provider Selection
# Options: "aws" (default) or "digitalocean"
S3_PROVIDER="aws"

# AWS S3 / DigitalOcean Spaces Credentials
AWS_ACCESS_KEY_ID="your-access-key-id"
AWS_SECRET_ACCESS_KEY="your-secret-access-key"
AWS_S3_BUCKET="soloshopbox-uploads"

# AWS S3 specific
AWS_REGION="us-east-1"
AWS_CLOUDFRONT_URL=""  # Optional: https://d12345abcde.cloudfront.net

# DigitalOcean Spaces specific (only needed if S3_PROVIDER="digitalocean")
DO_SPACES_REGION="nyc3"
DO_SPACES_ENDPOINT="https://nyc3.digitaloceanspaces.com"
```

### Bucket Setup (AWS S3)

1. **Create S3 bucket:**
   - Name: `soloshopbox-uploads` (or your custom name)
   - Region: `us-east-1` (or match `AWS_REGION`)
   - Public access: Block all **unchecked** (we need public-read for images)

2. **Set bucket policy for public-read:**
   ```json
   {
     "Version": "2012-10-17",
     "Statement": [
       {
         "Sid": "PublicReadGetObject",
         "Effect": "Allow",
         "Principal": "*",
         "Action": "s3:GetObject",
         "Resource": "arn:aws:s3:::soloshopbox-uploads/*"
       }
     ]
   }
   ```

3. **Create IAM user with S3 permissions:**
   - User name: `soloshopbox-uploader`
   - Attach policy: `AmazonS3FullAccess` (or create custom policy for just this bucket)
   - Generate access key → save as `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`

4. **Optional: Setup CloudFront CDN:**
   - Create distribution pointing to S3 bucket
   - Copy distribution domain: `https://d12345abcde.cloudfront.net`
   - Set `AWS_CLOUDFRONT_URL` in `.env`

### Bucket Setup (DigitalOcean Spaces)

1. **Create Space:**
   - Navigate to: DigitalOcean Console → Spaces
   - Name: `soloshopbox-uploads`
   - Region: `nyc3` (or your preferred region)
   - Enable CDN: **Yes**

2. **Generate API keys:**
   - Spaces → API → Generate New Key
   - Copy Access Key → `AWS_ACCESS_KEY_ID`
   - Copy Secret Key → `AWS_SECRET_ACCESS_KEY`

3. **Set environment variables:**
   ```bash
   S3_PROVIDER="digitalocean"
   AWS_ACCESS_KEY_ID="DO00ABCD1234EXAMPLE"
   AWS_SECRET_ACCESS_KEY="abc123secretkey..."
   AWS_S3_BUCKET="soloshopbox-uploads"
   DO_SPACES_REGION="nyc3"
   DO_SPACES_ENDPOINT="https://nyc3.digitaloceanspaces.com"
   ```

## How It Works

### Upload Flow

1. **Seller uploads image:**
   - Form submission from `/dashboard/products/new` or `/dashboard/products/[id]/edit`
   - File sent as `multipart/form-data` to `POST /api/products/upload`

2. **Server-side validation:**
   - File type check: only JPEG, PNG, WebP, GIF allowed
   - File size check: max 5MB
   - MIME type validation

3. **S3 upload (if configured):**
   - Sanitize filename: replace special chars with `_`
   - Generate unique key: `products/{timestamp}-{sanitized-filename}`
   - Upload to S3 with `public-read` ACL
   - Return CDN URL

4. **Fallback to local storage (if S3 not configured):**
   - Save to `public/uploads/{timestamp}-{filename}`
   - Return local URL: `/uploads/{filename}`

5. **Database storage:**
   - Save returned URL in `Product.imageUrl` field
   - Image served directly from URL in storefront

### File Naming

**Pattern:** `products/{timestamp}-{sanitized-filename}`

**Example:**
- Original: `My Product Image (1).jpg`
- Sanitized: `My_Product_Image__1_.jpg`
- Final key: `products/1716220800000-My_Product_Image__1_.jpg`
- CDN URL: `https://soloshopbox-uploads.nyc3.cdn.digitaloceanspaces.com/products/1716220800000-My_Product_Image__1_.jpg`

## Implementation Files

### `lib/s3.ts` — S3 upload utility

**Exports:**
- `uploadToS3(buffer, filename, mimeType)` → `Promise<{url, key, bucket}>`
- `isS3Configured()` → `boolean` (checks if required env vars are set)

**Features:**
- Auto-detects provider from `S3_PROVIDER` env var
- Constructs correct endpoint for AWS vs DigitalOcean
- Generates CDN URL based on provider
- Uses AWS SDK v3 (`@aws-sdk/client-s3`)

### `app/api/products/upload/route.ts` — Upload API endpoint

**Route:** `POST /api/products/upload`

**Request:**
- Content-Type: `multipart/form-data`
- Field: `file` (the image file)

**Response (success):**
```json
{
  "success": true,
  "url": "https://soloshopbox-uploads.nyc3.cdn.digitaloceanspaces.com/products/1716220800000-example.jpg",
  "filename": "1716220800000-example.jpg"
}
```

**Response (error):**
```json
{
  "error": "File too large. Maximum size is 5MB."
}
```

**Error codes:**
- `400` — Invalid file type, file too large, or no file provided
- `500` — S3 upload failed (after fallback attempt)

## Usage Examples

### In Product Form (Next.js)

```typescript
// app/dashboard/products/new/page.tsx
const handleImageUpload = async (file: File) => {
  const formData = new FormData()
  formData.append('file', file)

  const response = await fetch('/api/products/upload', {
    method: 'POST',
    body: formData,
  })

  const result = await response.json()

  if (result.success) {
    setImageUrl(result.url) // Save to state, then to DB
  } else {
    alert(result.error)
  }
}
```

### Direct S3 Upload (from lib)

```typescript
import { uploadToS3 } from '@/lib/s3'

const buffer = await file.arrayBuffer()
const result = await uploadToS3(
  Buffer.from(buffer),
  file.name,
  file.type
)

console.log('Image URL:', result.url)
// Save result.url to database
```

## Troubleshooting

### "AccessDenied" error
**Cause:** IAM user lacks `s3:PutObject` permission  
**Fix:** Update IAM policy to include `PutObject` on bucket ARN

### Images not loading (403 Forbidden)
**Cause:** Bucket policy doesn't allow public read  
**Fix:** Add bucket policy (see "Bucket Setup" above) or set ACL to `public-read`

### "NoSuchBucket" error
**Cause:** Bucket name mismatch or bucket doesn't exist  
**Fix:** Verify `AWS_S3_BUCKET` matches actual bucket name

### Upload works but returns local URL instead of S3
**Cause:** S3 credentials not set or `isS3Configured()` returns false  
**Fix:** Check all required env vars are set and non-empty

### DigitalOcean upload fails with "SignatureDoesNotMatch"
**Cause:** Incorrect endpoint or region  
**Fix:** Ensure `DO_SPACES_ENDPOINT` matches `https://{region}.digitaloceanspaces.com`

## Performance & Cost

### AWS S3 Pricing (2026 estimates)
- Storage: $0.023/GB/month (first 50TB)
- PUT requests: $0.005 per 1,000 requests
- GET requests: $0.0004 per 1,000 requests
- Data transfer out: $0.09/GB (first 10TB)

**Example cost for 1,000 products:**
- 1,000 images × 500KB average = 500MB storage = **$0.01/month**
- 1,000 uploads = **$0.005**
- 10,000 views/month = **$0.004**
- **Total: ~$0.02/month** (negligible)

### DigitalOcean Spaces Pricing
- Flat rate: **$5/month** (includes 250GB storage + 1TB outbound transfer)
- Overage: $0.02/GB storage, $0.01/GB transfer
- **Better for high-traffic shops** (predictable cost)

### CDN Benefits
- Faster image loading (edge caching)
- Reduced S3 egress costs (CDN absorbs most GET requests)
- **Recommendation:** Enable CloudFront (AWS) or Spaces CDN (DO)

## Migration Notes

### Switching from Local to S3
1. Set S3 env vars
2. Restart app
3. Old images remain at `/uploads/*` URLs (still work)
4. New uploads go to S3
5. **Optional:** Bulk migrate old images via script

### Switching from AWS to DigitalOcean
1. Change `S3_PROVIDER` to `digitalocean`
2. Update credentials and endpoint
3. Restart app
4. Test upload
